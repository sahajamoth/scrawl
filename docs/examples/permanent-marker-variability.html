Permanent Marker Variability Grades

Permanent Marker is a static font, not a true variable font. This demo fakes handwritten variation by jittering strokes, corners, label rotation, baseline offsets, tracking, and size. Use it to decide how far you want scrawl diagrams to drift from clean to loose.

Same diagram, five grades: `stable`, `subtle`, `balanced`, `loose`, `wild`.

If you want to use this in the renderer, the main knobs are: char rotation, baseline wobble, word spacing jitter, line bowing, and corner overshoot.
